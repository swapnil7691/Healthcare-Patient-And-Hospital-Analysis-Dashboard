🏥 Healthcare Patient & Hospital Analytics

📌 Project Overview

This project analyzes patient demographics, hospital appointments, appointment statuses, and consultation revenue using Power BI. The dashboard helps understand patient distribution, appointment trends, department performance, and billing insights.

🎯 Project Objectives

- Analyze total patients and appointments.
- Track completed and cancelled appointments.
- Understand patient demographics by age group, gender, and city.
- Analyze monthly appointment trends.
- Compare appointments across hospital departments.
- Evaluate consultation revenue by department.
- Monitor appointment completion rates.

🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- CSV datasets
- Data Modeling & Visualization

📂 Dataset Files

- "patients.csv" — Patient demographic information.
- "appointments.csv" — Appointment details, departments, dates, and statuses.
- "billing.csv" — Patient billing and revenue information.

🚀 How to Use

1. Download or clone this repository.
2. Open "Healthcare_Patient_Hospital_Analytics.pbix" using Microsoft Power BI Desktop.
3. If required, update the CSV file paths in Power BI.
4. Refresh the data to view the dashboard.

⚠️ Data Disclaimer

This project uses synthetic sample data created for educational and portfolio purposes. It does not contain real patient records or represent live hospital data.
